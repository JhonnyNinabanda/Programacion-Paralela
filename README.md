# Programación Paralela

Repositorio de prácticas y ejercicios desarrollados durante la asignatura de Programación Concurrente y Paralela.

## Contenido

### 00_Ejemplo
Configuración inicial del entorno C++ con GCC, CMake y VS Code.

### 01.fractal-julia
Implementación serial del Fractal de Julia utilizando SFML.

Temas:
- Coordenadas cartesianas
- Números complejos
- Paletas de colores
- Renderizado de imágenes

### 02.fractal-dll
Implementación SIMD utilizando AVX2.

Temas:
- Vectorización
- SIMD
- AVX2
- Intrinsics
- DLL en C++

### 03.fractal-java
Consumo de la DLL desde Java mediante JNR-FFI.

Temas:
- Interoperabilidad Java/C++
- DLLs
- Native Libraries
- JNR-FFI

## Tecnologías

- C++
- GCC 16.2
- CMake
- SFML
- AVX2
- Java
- Gradle
- JNR-FFI
